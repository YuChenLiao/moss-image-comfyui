# 构图拆解与校准

`replication.md` 管"把参考图拆成八项去复刻"，本篇管"构图本身怎么量、怎么判、怎么学"。两份合起来用：先拆八项，再用本篇量构图。

## 取舍：为什么不是照搬摄影教材

网上那套构图资料（三分法、焦距、光圈、镜头运动）大部分是给摄影和电影写的，MOSS 是文生图模型，很多参数**没有对应实现**，写进提示词只是白占 token、还可能把模型带偏。所以只留下"能改变出图结果"的那部分。

| 丢弃 | 原因 | 用什么替代 |
|---|---|---|
| 焦距 mm、光圈 f 值、ISO、快门 | 文生图模型没有镜头物理，写 `35mm` `f/1.8` 只会稀释真正的控制词 | 写**效果**：`广角夸张透视` / `长焦压缩、背景更近` / `浅景深、背景虚化` |
| 推镜头、摇镜头、升降、斯坦尼康 | 视频语言，静止图无意义 | — |
| 三分网格坐标、黄金螺旋角度 | 对角色图收益极低，还会跟主体占比抢权重 | 只写"主体偏左/偏右、留白在哪一侧" |
| 器材、品牌、色彩空间、印刷/扫描工艺词 | 与画面无关 | — |
| 强制 JSON 表单、版本校验、强制署名水印 | 出图流程用不上，还污染画面 | — |
| 美食/建筑/车辆/科技等分类路由 | 这套 skill 只做二次元角色图 | 只保留"角色图/氛围图/构图图"三分 |

留下的是：**机位与占比的量化、画面轴线、层次、光比与色块、8 条判据、崩法对照、以及"一次只改一个变量"的校准回路**。

## 第 0 步：先判这张图靠什么成立

不同类型，构图该花多少力气完全不同。

| 类型 | 特征 | 构图策略 |
|---|---|---|
| 角色图 | 靠脸、表情、服装、动作 | 构图只服务"主体够大、关节不被切"，别把机位写复杂 |
| 氛围图 | 靠光、色、景，人物可小 | 构图服务层次与留白，允许人物占比 30–50% |
| 构图图 | 靠几何、对称、引导线、框架 | 必须写死轴线与网格关系，否则一定不像 |

判错的典型：拿"构图图"的复杂机位去套角色图，结果脸小了、手指也崩了。

## 第 1 步：量四项硬指标

这四项都能直接写进提示词，也都能当判错依据。

| 指标 | 怎么读 | 怎么写 |
|---|---|---|
| 画幅比例 | 宽 ÷ 高，约到最简 | 直接给像素（16 的倍数、≤2.3MP）：`1312×1744` |
| 机位高度 | 与主体视线比：齐平 / 更高 / 更低 / 正上方 | `平视` / `略俯视` / `俯视` / `从正上方俯视` |
| 水平朝向 | 正面 / 侧面 / 3-4 侧 / 背面 | `正面` / `侧脸` / `身体向观者左侧转约四十五度` / `背对镜头` |
| 主体占比 | 主体最长边 ÷ 画面对应边 | `人物占画面约七成，四周留白`（占比配留白一起写才生效） |

## 第 2 步：找画面轴线

这一项最容易被忽略，但它决定"像不像"的程度往往超过机位。

| 轴 | 读什么 | 写法 |
|---|---|---|
| 主体轴 | 躯干/脊柱的倾斜方向 | `脊柱轻微侧弯，胯部向右顶` |
| 视线轴 | 脸朝向 **与** 眼睛看向哪里（两者可以不同，张力就在这） | `头微微低下，眼睛从下往上看镜头` |
| 对角线 | 头与脚的连线是否斜穿画面 | `头部位于右上方，双腿向左下延伸构成对角线` |
| 框架 | 有没有门窗、拱、手臂、头发形成的框 | `前景是窗框，把人物框在中间` |
| 引导线 | 有没有把视线送到主体身上的线 | `地面上的黑色长带从画面左下引向人物` |

只写图里真实存在的，2–3 条就够。写多了彼此打架。

## 第 3 步：层次与景深

先问三句：前景有东西吗、主体在第几层、背景有没有抢戏。

| 情况 | 写法 |
|---|---|
| 有前景元素 | `前景是虚化的花枝，位于画面左下` |
| 没有前景 | `背景干净，没有多余物件` |
| 要突出主体 | `浅景深，背景虚化成光斑` |
| 要全景清晰 | `前后都清晰，场景完整` |

MOSS 里不要写 f 值，写"浅景深/背景虚化"这种效果词就够。

## 第 4 步：光比与色块

光线方向、软硬在 `prompting.md` 与 `replication.md` 里讲，这里只管**量**。

| 项 | 读法 | 写法 |
|---|---|---|
| 光比 | 主光面与暗部的明暗差 | `强光比，主光从右后方斜射，暗部沉入冷灰` |
| 色块 | 画面由 2–3 个主色构成，各占多大面积 | `深红背景为主，白色衣物为次` |
| 色温 | 整体偏冷 / 偏暖 / 中性 | `整体偏冷，高光带一点暖白` |

别罗列颜色清单（"红、白、黑、金、粉"），要写成"主色 + 面积 + 位置"。

## 判据：出图后逐条打勾

八条，不过哪条就改哪条，不要整段重写。

1. **重心稳**：主体重心落在画面中线附近，或有意偏置且另一侧有元素压住
2. **占比合理**：角色图 40–70%；低于 35% 脸必糊，高于 80% 关节必被切
3. **视线有去处**：视线那一侧留白 ≥ 另一侧
4. **关节不被切**：手腕、肘、膝、踝不落在画框边缘
5. **层次可分**：前景 / 主体 / 背景三层能一眼分开
6. **引导不对冲**：画面里的线不把视线带出画外
7. **边缘干净**：画框处没有半截物件、多余肢体
8. **轴一致**：脸朝向、视线、躯干扭转三者不互相打架

## 常见构图崩法 → 改法

都是这台机器上实际踩过的。

| 症状 | 根因 | 改法 |
|---|---|---|
| 臀胯被放大成主角 | 俯拍 + 臀部特写构图 | 镜头与腰齐平、人物占比降到六成、负面压 `huge butt, wide hips, thicc` |
| 前臂过长 | 手撑地承重 | 改成手搭在支撑物上，写"前臂到手腕为止" |
| 手被裁、手指糊 | 9:16 参考图把人物撑满 | 参考图垫成 4:5 居中，写"各部位留边距、无裁切"，负面 `hands out of frame` |
| 多肢、腿融合 | 趴姿 + 翘臀 + 身体扭转三重叠加 | 换对称姿势（如鸭子坐），负面 `extra legs, fused legs` |
| 主体没气场 | 全景 + 留白过多 | 占比提到 65–75%，或直接改中景 |
| 层次糊成一片 | 背景与主体明度接近 | 拉开光比或明度差，写"背景比人物暗一档" |
| 画面发飘 | 没有前景也没有暗部压边 | 补前景元素或压暗四角 |

## 学习法：从多张好图里提炼可迁移规则

不是"多看"，是**一次只验证一个变量**的闭环。

1. 同主题取 5–10 张（同一画师、同一构图类型、同一景别）
2. 只记共性，不记单张细节（例：都用手肘外张、头微低、视线斜上）
3. 归纳成 3 条以内可执行句 + 1 条负面，其余全部丢掉
4. 出图，用上面 8 条判据逐条比对
5. **一次只改一个变量**——换 seed 不算改，改描述算
6. 一条规则能解释 ≥2 张图的成败才值得写回文档；单张图的问题只修当前输出

第 5 条最容易被违反：同时改机位、占比、光线、服装，出了好图也不知道是哪条起的作用。

## 成像签名四层分离

拆光影时最容易犯的错是把"光"和"后期"混成一句"氛围感很强"。分四层写，跨层共存不矛盾：

| 层 | 内容 | 例子 |
|---|---|---|
| 固有属性 | 皮肤/头发/服装本来的颜色与材质 | 暖象牙肤色、哑光棉布 |
| 光线层 | 方向、软硬、色温、落点、轮廓光 | 主光从右后方斜射，边缘有一圈暖白轮廓光 |
| 曝光层 | 高光是否接近溢出、暗部是否压死 | 受光面明亮但不溢出，暗部保留细节 |
| 后期层 | 柔焦、颗粒、锐化、色偏、美颜 | 皮肤微对比降低，整体轻微柔焦 |

判据：暖肤色 + 冷白面部提亮 + 暗背景 + 局部高曝光**可以同时成立**；只有同层冲突（比如"高光溢出"配"高光有细节"）才是真矛盾。

## 落到出图链路

| 拆解结论 | 写在哪 |
|---|---|
| 机位高度、水平朝向 | 中文首句：`从正上方俯视，身体向左侧转约四十五度` |
| 主体占比 | `人物占画面约七成，四周留白，任何部位不被裁切` |
| 轴线、对角线 | `头部在右上方，双腿向左下延伸构成对角线` |
| 层次 | `前景是虚化的花枝；背景干净无杂物` |
| 光比、色温 | `强光比，主光从右后方斜射，暗部沉入冷灰` |
| 色块 | `深红背景为主，白色衣物为次` |
| 极端透视 | 只写效果词：`广角夸张透视` / `长焦压缩` / `顶视俯拍`，不写 mm |
