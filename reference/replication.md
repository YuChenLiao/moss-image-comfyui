# 参考图复刻

用户丢一张参考图说"换成某某"时按这套走，别凭感觉写。

## 第一步：拆成八项

主体身份、服装（款式/材质/长度/配饰）、道具、场景、光线、视角与构图、姿势、表情。逐项写成清单，这是后面逐轮修正的对照表。

## 第二步：判断替换与保留

- 身份类（发色、瞳色、光环、耳尾、身高体型）→ 全部换成目标角色的官方设定。
- 构图类（机位、视线方向、身体朝向、画面留白、画框形状）→ 保留。
- 服装道具场景光线 → 保留，按需修正不合理处（材质、长度）。
- 参考图的角色特征**不能残留**：把原角色的发色瞳色写进负面（`blonde hair, blue eyes, red hair`），否则会串。

## 第三步：写提示词

tag 段放身份锚点；中文段按"场景 → 姿势 → 服装 → 道具 → 光线 → 氛围"顺序写；收尾给画幅与视角。

### 动作必须写到关节

姿势是最容易漂的一项，因为形容词天生含糊："侧躺"能画出几十种结果。写动作时把下面四个维度全部落到具体位置，缺哪个维度，模型就在哪个维度上自由发挥。

| 维度 | 笼统写法（会漂） | 精确写法（能压住） |
|---|---|---|
| 身体朝向 | 侧躺 | 上半身向左转约三十度，背对镜头，头只侧过一点、露出左侧脸颊边缘 |
| 重心 | 站着 | 重心落在右腿，左腿放松、脚尖点地 |
| 关节角度 | 抬手 | 手肘弯曲约九十度，前臂向上，手掌托住侧脸 |
| 手脚落点 | 拿着钥匙 | 左手举到脸侧，拇指与食指捏住钥匙尾端，其余三指自然弯曲 |

自查方法：写完动作通读一遍，问"重心在哪、朝向哪边、关节弯曲多少、手脚具体在哪"，答不上来的那项就是会被画歪的那项。

## 第四步：逐项核

对着出图核八项清单，哪项不对就定位到描述词改，不要整体重写。

## 不要照搬原角色的固有特征

参考图里的角色可能自带翅膀、兽耳、尾巴、特殊发饰。这些是**那个角色**的设定，不是构图元素，换角色时必须一起换掉。

判断标准：问一句"目标角色官方设定里有没有这个"。没有就不能留——构图语言（机位、视线方向、身体朝向、画面留白、画框形状）才是要复刻的东西。

实测踩坑：把参考图的黑色羽翼直接搬到了 Miyo 身上，而她是人族学生、没有翅膀。修正方式是删掉描述并在负面压 `wings, feathered wings`。

## 修正对照表

实战高频问题与对策，都是在这台机器上试出来的。

| 症状 | 对策 |
|---|---|
| 支撑物变多（一只抱枕变成两只、靠垫重复） | 只写"一个巨大的抱枕"不够。正向要写死"画面里只有一只 X，她只靠在这一只 X 上"，负面压 `two pillows, multiple pillows, extra pillow`。实测前两版都会凭空长出第二只，腿一旦去压它就更明显 |
| 腿被抬高、脚翘到画面上方 | 别用"膝盖弯曲搭在另一条腿上"——"搭在…上方"会被理解成高抬腿。改成"右腿屈膝侧放、小腿贴地、脚背朝下"，负面压 `raised leg, leg up, foot in the air` |
| 腿被拉长、大头 | 姿势换成折叠态（抱膝、蜷坐），加"四肢长度自然，头身比例正常，头部与肩宽协调"，负面压 `long legs, elongated body, big head` |
| 手指畸形 | 正向"双手五指分明，每只手五根手指，关节位置正确"，负面 `extra fingers, six fingers, fused fingers, bad hands` |
| 服装跑偏 | 长度与材质双写（"极短只到大腿根部"+"薄纱半透明"），负面反向压（`long dress, opaque fabric, thick lace`） |
| 表情不对 | 拆成嘴形 + 眼型 + 脸红三件事分别写，负面排除（`closed mouth, serious expression, closed eyes`） |
| 构图变形 | 用方位描述死（"头部位于右上方，双腿向左下延伸构成对角线"），点名主体在画面中部 |
| 头上多出东西 | 负面压 `white horns, extra hair ornaments, animal ears`（兽耳角色除外） |
| 双人角色串味 | 分别写明左右位置与各自特征，负面压对方的发色瞳色 |
| 画面发闷 | 加 `high key, luminous, hazy, dreamy`；但**光柱与朦胧感在 MOSS 里互相拉扯**，提亮就会吞掉丁达尔光柱，二者只能选一个 |
| 元素缺失 | 顺序错乱（中文混进了 character/series 段之间），按官方顺序重排 |
| 角色特征错 | 用了中文角色名或错误 tag，先查 Danbooru 官方标签再写 |
| 画面突然变水墨或厚涂 | 缺 `anime style, cel shading`；或换了 `@wlop` 这类半写实画师 |
| 造型改动不动（换发型、加耳饰、改服装形制） | 角色 tag 的先验会压过中文描述。把改动写成 tag 塞进 tag 区（`twintails, high twintails, black hair ribbon`），负面压 `loose hair, long hair down`。实测：同一段中文描述改两轮无效，换 tag 一次生效 |
| 姿势飘（朝向、站姿、手放哪都不对） | 按"朝向/重心/关节角度/手脚落点"四个维度逐项写死，见上文「动作必须写到关节」 |
| 服装凭空消失（该穿的内衣/配饰没了） | 点名部件而非笼统说"穿着"：把"穿着胸罩"改成"两肩细肩带与绕到背后的横向背带都清晰可见、贴合后背，蕾丝纹样能看清"，负面加 `topless, no bra, bare chest, missing clothing` |
| 换了角色却带着原角色的特征（翅膀、兽耳、特殊发饰） | 参考图角色的固有设定不是构图元素，按目标角色官方设定删掉，负面压对应词（`wings, feathered wings, animal ears`） |
