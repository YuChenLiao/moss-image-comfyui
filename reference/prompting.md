# 提示词工程

## 复杂度分级

按需求选档，不要默认上最重的那档。

**L1 极简**（试构图、快速迭代，20 步）：纯 tag。`masterpiece, best quality, 1girl, solo, city street at night` + 画师。

**L2 混合**（出成品默认）：tag 锚身份 + 中文写一段场景，就是 SKILL.md 里的混合模板。

**L3 全描述**（精确控制元素）：tag 锚身份 + 中文分句写满动作、材质、方位、光线、道具。中文可写到 200 字以上，MOSS 不丢元素。

判断依据：改构图、试风格用 L1；出成品用 L2；复刻参考图或多道具场景用 L3。

## 维度清单

扩写或复刻时逐项过一遍，**只取需要的，不要塞满**。

| 维度 | MOSS 里怎么写 |
|---|---|
| 主体身份 | Danbooru 角色 tag（`miyo (blue archive)`），作品 tag 进 series 段 |
| 风格 | `@画师` + `anime style, cel shading, clean lineart` |
| 服装 | 中文写材质与结构：`白色薄纱吊带短裙，纱质轻薄半透明，细肩带` |
| 动作姿势 | 中文写关节关系：`抱膝蜷坐，双臂环抱小腿，下巴抵在膝盖上` |
| 场景 | 中文写空间层次与材质：`玻璃温室，金属框架的玻璃窗，悬挂的玻璃球` |
| 光线 | 中文写方向与性质：`光从左上斜射，斑驳树影，逆光让发丝边缘透亮` |
| 视角构图 | 中文写机位与画框：`俯视视角`、`头部在右上方、双腿向左下延伸构成对角线` |
| 道具 | 中文逐件点名并给位置：`左脚边木盘里切好的西瓜和一把小刀` |
| 表情 | 中文写嘴形眼型：`嘴巴微张成小圆，眼睛半睁，脸颊泛红` |
| 画幅 | 直接定尺寸（16 倍数，≤2.3MP），宽高比决定构图 |

## 质量检查

主体明确；角色用官方 tag 而非中文名；风格词都起作用（没堆砌）；中文描述里没有自相矛盾的动作；负面提示词覆盖了本张最容易崩的项（手指、比例、透视、多余发饰）。

## 变量模板

做系列图、换角色重跑、反复迭代同一套构图时，把提示词拆成变量。**前三项必须是英文 tag**（身份锚点，写中文会失效），**后面全是中文**（场景语义，写成 tag 反而不准）。

```
masterpiece, best quality, anime style, cel shading,
{{character_tag}}, {{series_tag}}, @{{artist}},
{{outfit}}，{{pose}}，{{scene}}，{{props}}，{{lighting}}，{{mood}}，{{composition}}
```

| 变量 | 写法要求 | 候选值 |
|---|---|---|
| `character_tag` | Danbooru 官方角色标签，不能写中文名 | `miyo (blue archive)` / `plana (blue archive)` / `misono mika` / `mari (blue archive)` |
| `series_tag` | Danbooru 作品标签 | `blue archive` / `genshin impact` / `pokemon` |
| `artist` | `@` + Danbooru 画师名 | `@ciloranko`（明亮现代二次元，默认）/ `@wlop`（半写实厚涂夜景）/ `@nekojira`（柔和）/ `@akino_ell`（甜美）/ `@fuzichoco`（华丽和风） |
| `outfit` | 材质 + 款式 + 长度 + 配饰，四件都写 | 白色薄纱吊带短裙，纱质轻薄半透明，细肩带 / 深藏青女仆装，白色蕾丝围裙，绿色领结 / 黑色哥特洋装，泡泡袖，黑色蕾丝系带，深紫缎带蝴蝶结 |
| `pose` | 关节关系 + 身体朝向 | 抱膝蜷坐，双臂环抱小腿，下巴抵在膝盖上 / 侧躺，一手撑地，一手举着红苹果 / 跪坐，双手撑在身前，身体前倾 |
| `scene` | 空间层次 + 材质 + 远近景 | 玻璃温室，金属框架玻璃窗，空中悬挂着装多肉的玻璃球 / 雨中的城市街道，湿漉漉的柏油路面，朦胧建筑与电线杆 / 花园台阶，四周繁盛花丛，木质棚架 |
| `props` | 逐件点名 + 给位置 | 左脚边木盘里切好的西瓜和一把小刀 / 手中举着一个鲜红的苹果 / 左下角白色拖把与拖把桶 |
| `lighting` | 方向 + 性质 + 效果 | 光从左上斜射，斑驳树影落在她身上 / 逆光让发丝与裙摆边缘透亮发光 / 暖金色光从上方洒落，空气中有浮尘 |
| `mood` | 情绪 + 色调 | 安静治愈的夏日午后，暖色调 / 幽静哥特的暗调，几乎全黑的背景 / 明亮通透如清晨薄雾 |
| `composition` | 机位 + 视线 + 画框关系 | 俯视视角，裙摆在地面展开成圆形 / 头部在右上方、双腿向左下延伸构成对角线 / 侧上方视角，腿部占据画面大部分 |
| `aspect` | 直接定尺寸，16 倍数，≤2.3MP | 1264×1808 竖 / 1888×1232 横 / 2224×1008 超宽 |

**替换规则**：换角色只动 `character_tag` 和 `series_tag`，其余全部复用；换画风只动 `artist`；同一套构图做 N 个角色版本时，把原角色的发色瞳色写进负面防串色。
